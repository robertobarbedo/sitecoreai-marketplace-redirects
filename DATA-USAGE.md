# Data usage disclosure

Redirects is an app that runs inside SitecoreAI and manages the SXA redirect
items of a site: list, create, edit, delete, publish and test them. Managing
redirects works entirely in the browser through the Sitecore Marketplace
SDK, with the signed-in user's own permissions. Testing calls the app's own
server, which follows the redirect's live URL hop by hop and returns status
codes and URLs only. The app has no database, uses no analytics and no AI;
what it saves goes to the customer's own SitecoreAI environment. Hosting:
Vercel; serverless functions run in the United States (Vercel default region
`iad1`, Washington, D.C.) unless the deployment sets another region.

See also the [Privacy policy](PRIVACY.md) and [Security policy](SECURITY.md).
